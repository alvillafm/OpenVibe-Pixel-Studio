# OpenVibe Pixel Studio

A free, open-source pixel art editor built with AI-assisted coding.

OpenVibe Pixel Studio is a personal project I started while developing my own pixel art game. I wanted to see if I could create a useful alternative to existing editors using OpenAI Codex, and decided to share the result with everyone.

The editor is completely free and released under the MIT License. Anyone can use it, modify it, or contribute to its development.

## Features

- Pixel art drawing tools: pencil, eraser, shapes and eyedropper.
- Indexed color palettes with editable colors.
- Custom canvas sizes and common resolution presets.
- Project management and recent files.
- Layers and tools for creating game assets.
- Web-based interface.

The project is still in development, so expect bugs and unfinished features.

## About the project

This project was developed with the help of OpenAI Codex. I'm not trying to hide that. I wanted to experiment with AI-assisted development and see how far I could take it.

I'm sharing the source code because I believe it could be useful to other pixel artists and indie developers.

It's not intended to replace Aseprite or other established tools. It's simply another free option that I hope to keep improving.
